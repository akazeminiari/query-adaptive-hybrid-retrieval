# Historical ArguAna Audit

This directory preserves historical and exploratory
ArguAna analysis artifacts for transparency.

The original ArguAna evaluation included improper
same-ID query-document matches and is not
BEIR benchmark-compliant.

Historical results are retained only for auditability.
They must not be interpreted as confirmatory findings.

See the main manuscript and supplementary material
for the corrected ArguAna results and limitations.
